# 🎬 VideoCompressor

Автономная консольная утилита для быстрого и удобного пакетного сжатия видеофайлов под заданный размер и разрешение на Windows.

---

## ⚡ Быстрый старт (для пользователей)

Вам **не нужно устанавливать Python или FFmpeg** — программа уже полностью собрана в один исполняемый файл:

👉 **[Скачать VideoCompressor.exe (последний релиз)](https://github.com/kostin/VideoCompressor/releases/latest/download/VideoCompressor.exe)**

### Как пользоваться:
1. Поместите файл `VideoCompressor.exe` в папку с вашими видеофайлами.
2. Запустите его двойным кликом.
3. Ответьте на вопросы в меню (или просто нажимайте **Enter** для выбора рекомендуемых значений по умолчанию).
4. Сжатые файлы будут сохранены в подпапку `compressed/`.

## ✨ Возможности утилиты

- 📦 **Полная автономность**: внутри EXE-файла уже упакованы среда исполнения и полноценные бинарники `ffmpeg` / `ffprobe` с поддержкой кодеков H.264 (`libx264`) и H.265 (`libx265`).
- 🎯 **Точный расчет битрейта под целевой размер**: вы задаете желаемый размер в МБ (например, `300 МБ`), и программа автоматически вычисляет битрейт исходя из длительности каждого видео.
- 📐 **Умное масштабирование по меньшей стороне**: по умолчанию `1080p`. Корректно определяет горизонтальные (альбомные) и вертикальные (мобильные) видео, сохраняя исходные пропорции без искажений и округляя размеры до четных пикселей.
- ⏭️ **Умный пропуск подходящих видео**: если исходное видео уже меньше или равно целевому размеру и разрешению (и не включены субтитры/удаление звука), оно просто копируется в папку `compressed/` без потери качества и траты времени.
- ⚡ **Режимы 1 и 2 проходов**:
  - **1 проход**: в ~2 раза быстрее.
  - **2 прохода** (по умолчанию): максимальная точность попадания в целевой размер и оптимальное распределение качества по сложным сценам.
- 📝 **Наложение субтитров из имени файла**:
  - Текст берется из названия видеофайла.
  - Символ `@` автоматически превращается в перенос на новую строку `\n`.
  - Субтитры аккуратно накладываются в левом нижнем углу.
- 🔇 **Опция удаления звука**: возможность полностью убрать аудиодорожку, отдав весь битрейт под максимальное качество видео (или чтобы избавиться от нежелательной озвучки).
- 📊 **Информативный цветной прогресс-бар**: отображает процент выполнения, скорость кодирования, прошедшее время и точный расчет оставшегося времени (**ETA**).
- 🛡️ **Безопасность видео-исходников**: оригинальные файлы никогда не перезаписываются.

## 📁 Поддерживаемые форматы исходных видео
`.mp4`, `.mov`, `.mkv`, `.avi`, `.wmv`, `.flv`, `.webm`, `.m4v`, `.ts`, `.mts`, `.m2ts`, `.3gp`

## 🖥️ Интерактивное меню

При запуске утилита предлагает следующие настройки (каждая с вариантом по-умолчанию, что позволяет не задумываясь нажимать Enter, Enter, Enter…):

```text
1) Введите целевой размер видео в МБ [300]:

2) Введите целевое разрешение по меньшей стороне в px [1080]:

3) Выберите кодек сжатия:
   [1] H.264 (AVC) — максимальная совместимость с любыми плеерами/телевизорами [По умолчанию]
   [2] H.265 (HEVC) — лучшее качество при сильном сжатии (требует больше времени)
Ваш выбор [1/2]:

4) Режим кодирования:
   [1] 1 проход  — в ~2 раза быстрее (размер может незначительно отклоняться от целевого)
   [2] 2 прохода — максимальная точность размера и оптимальное качество [По умолчанию]
Ваш выбор [1/2]:

5) Наложение субтитров:
   [1] Не накладывать [По умолчанию]
   [2] Наложить субтитры. Текст для субтитров будет взят из имени файла. Если в имени встретятся символы @, то вместо каждого такого символа будет сделан переход на новую строку в субтитрах
Ваш выбор [1/2]:

6) Убрать звук:
   [1] Не убирать [По умолчанию]
   [2] Убрать. В этом случае из видео будет полностью удалена звуковая дорожка
Ваш выбор [1/2]:
```

## 🛠️ Разработка и сборка

### Запуск из исходного кода:
```powershell
python compress_videos.py
```
или двойным кликом по `run_compressor.bat`.

### Локальная сборка в EXE:
Для ручной пересборки автономного исполняемого файла:
```powershell
python build_exe.py
```
или двойным кликом по `build_exe.bat`.

### Автоматическая публикация релиза на GitHub:
При отправке тега версии GitHub Actions автоматически соберет `.exe` на Windows-раннере и опубликует релиз:
```powershell
git tag -a v1.0.1 -m "Release v1.0.1"
git push origin v1.0.1
```
