# VideoCompressor

Скрипт и утилита для пакетного сжатия и конвертации видеофайлов с графическим интерфейсом на базе `customtkinter` и `ffmpeg`.

## Возможности
- Пакетная обработка видео в указанной папке.
- Гибкая настройка кодеков (H.264, HEVC/H.265, AV1), CRF, разрешения и пресетов.
- Поддержка многопоточной / пакетной обработки.
- Сборка в один автономный `.exe` файл (PyInstaller).

## Структура проекта
- `compress_videos.py` — основной скрипт и GUI приложение.
- `build_exe.py` / `build_exe.bat` — скрипты сборки автономного исполняемого файла.
- `run_compressor.bat` — запуск приложения без терминала.
- `.gitignore` — исключение тяжелых бинарников (`ffmpeg.exe`, `ffprobe.exe`) и временных файлов сборки.
